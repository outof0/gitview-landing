# Security Policy

Do not open a public issue for a vulnerability.

Report it through [GitHub Security Advisories](https://github.com/outof0/gitview-landing/security/advisories/new)
or email `hello.outof0@gmail.com`. Include the affected URL or commit, a minimal
reproduction, and the impact. You can expect acknowledgement within seven days.

For vulnerabilities in the VS Code extension itself, use the
[extension security policy](https://github.com/outof0/gitview/blob/main/SECURITY.md).
